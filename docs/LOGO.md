# EdgeX monochrome mark

The PNG at site/assets/edgex-mark.png was generated using the built-in image
generation tool for this project. It uses nearly black geometry and alpha
transparency; place it on an ivory/white background for contrast.

Final generation prompt:

> Use case: logo-brand. Create a finished monochrome identity mark for EdgeX, a scientific research agent. Single icon, no text. Black geometry on a genuine transparent background. A distinctive compact interlocking E and X built from four bold precisely cut angular strokes; deliberate negative space, recognizably directional, not a generic sparkle/star/robot/cube/atom. Flat two-dimensional vector-like hard edges, no gradients, shadows, 3D, texture, frame or mockup. Square composition with generous transparent margins. Suitable as a small app/plugin icon and a large editorial website emblem. This is the final black logo asset.
