# EdgeX multi-page showcase

This directory is the complete static GitHub Pages artifact. Publish the contents of `site/` as the Pages artifact root. No build step or runtime service is needed. Relative links and asset paths work under the project URL `/edgex-agents/`.

Preview from the repository root:

```sh
python3 -m http.server 4173 --directory site
```

Open http://127.0.0.1:4173.

- `index.html`: project introduction and copyable primary install command.
- `install.html`: complete Codex setup, native marketplace steps, portable skills, and prerequisites.
- `method.html`: controller protocol, policy, and three illustrative decision traces.
- `agents.html`: native researcher and twelve specialist roles.
- `styles.css`: shared responsive monochrome identity and reduced-motion support.
- `script.js`: copy feedback and the fixed illustrative example selector.
- `assets/edgex-mark.png`: transparent black logo shown on ivory.
- `assets/feral-grain.webp`: optimized Feral UI Lantern grayscale grain used at low opacity on ivory surfaces.
- `ASSET-CREDITS.md`: source and usage terms for the third-party texture.
- `DESIGN.md`: design dials, rationale, and interaction rules.
- `BRAND.md`: reusable identity and content prompt.
- `ANTI-SLOP-DELIVERY.md`: build review, evidence, and remaining browser checks.

The examples are not live research or controller outputs. No external fonts, frameworks, analytics, or application network calls are used. Commands remain visible and selectable if JavaScript is disabled.
