EdgeX / 03 · Agent team

One researcher.
Twelve perspectives.

The native Codex agent edgex_researcher coordinates a persistent research run and brings in specialist roles when the question needs them.

Coordinator / Codex agent

Research with
a working record.

The researcher sets a bounded plan, proposes next actions, reads and updates persistent run state, and resumes from the run ID. The controller compares candidate actions and records decisions, observations, evidence references, and artifacts.

Models, tools, permissions, and delegation come from the host. EdgeX does not start a background research service. Native delegation depends on the host; sequential role passes should be described as sequential work.

Specialists, when relevant.
