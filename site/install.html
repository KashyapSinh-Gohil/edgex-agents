Recommended / Codex

One command.
Complete setup.

Install the tagged release directly from GitHub. The installer checks existing Codex state before adding or updating the EdgeX plugin and researcher.

Terminal / NPX · GitHub release
npx --yes github:KashyapSinh-Gohil/edgex-agents#v0.4.0

This is a GitHub-distributed NPX package. It is not an npm registry publication. After install, restart Codex to load the integration.

Prerequisites

Node.js 18+ · Python 3.10+ · Git · Codex

No separate model API key is required for this setup. The host supplies model access and execution permissions.

The complete NPX route is the simplest way to install the native Codex agent and research tools together.

02 / Native marketplace

Add the plugin from Codex.

This adds the EdgeX plugin and its MCP server. For the separately installed named native agent, use the recommended NPX setup.

Terminal / Codex
codex plugin marketplace add https://github.com/KashyapSinh-Gohil/edgex-agents.git
codex plugin add edgex@edgex-agents

03 / Portable skills

Install into a project.

From your project directory, add portable skill files for supported coding agents. This route does not configure native MCP tools or the Codex researcher.

Terminal / uv
uvx --from "git+https://github.com/KashyapSinh-Gohil/edgex-agents.git@v0.4.0" edgex install --target all --project .

Requires uv. Choose --target codex for Codex only, or add --dry-run to preview files.
